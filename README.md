Die eSports Plattform ist eine Verwaltungs-Webanwendung, die der Verwaltung von eSports Teams mittels Konten der Spieler und Teamleader, sowie das ERstellen und Verwaltuen von Turnieren durch Admins und JourNex Operator ermöglicht. 
Ebenso können sich dort die Teams bei den erstellten Turnieren anmelden.
